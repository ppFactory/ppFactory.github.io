2. Description of Service

HairWise is a hair health analysis application for iOS devices that allows users to:

5.1 Hair Health Analysis

The App provides AI-powered hair and scalp analysis through Alibaba DashScope’s AI service. This analysis:

5.2 Data Processing for AI Analysis

When you request hair analysis:
